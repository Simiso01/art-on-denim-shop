# Demo script

Say this while the website is on screen, then show the same account on the phone or emulator.

Open Art on Denim. This is the same South African store on the website and in the app. Prices are in rand, and shipping is free over one thousand five hundred rand.

Sign in as Lebo. The password is the demo password in the readme.

Open the shop and a product. Choose a size. Add it to the bag. Apply WELCOME10. The total changes on the website, and the app reads that same bag.

Place an order with a South African address and EFT. The order number appears. Open orders and show the timeline.

Open the journal and ask the studio about shipping.

On the app, sign in as Lebo again. The home page uses the same words: Denim craft, designer edge, new arrivals, the house edit, sale, and the journal. The bag and the order are the same records.

Google sign-in is on both, and it stays off until a Google client is added. It is not a second password form.

Do not say a phone test happened unless the app is actually running on that phone.
